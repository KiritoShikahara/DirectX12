### プロジェクト概要

人数：１名（個人開発）

### ビルドに関して

- 構成 
 - 開発中： Develop
 - リリース版： Release


基本的には、Visual Studio（MSVC）でコンパイルしてます。




### 仕様技術

言語：C++20

シェーダー:HLSL

IDE：Visual Studio 2026 / 2022

外部ライブラリ:Jolt Physics など


### 工夫した点

- データのホットリロード機能の実装
  - 背景: コンパイルを止めることなく調整などをしたかったため。
  - 内容: パラメータのCSV/DB化、およびインゲームGUIからの動的変更・即時変更環境の作成。外部ツール不要で調整可能な環境の構築。

- マルチスレッド化（ジョブシステムの導入検証）
  - 背景: パフォーマンスの低下を確認したためマルチスレッドでパフォーマンス向上を狙っていた。
  - 内容: ジョブシステムの独自実装を進め、「マルチスレッドレンダリング」や「物理エンジンとECSの連携」を見据えた並行処理アーキテクチャの設計・検証を実施。
