# コメント規約

このドキュメントのルールは絶対順守。

---

## 共通(.h / .cpp)
- `()` は使用しない。
- `=====` のような区切り線は使用しない。
- `-----` のような区切り線は使用しない。
- コメントの修正のみのタスクでは、ロジックコードは絶対に変更しない。
- 文字化けしているコメントを見つけた場合、元の文言を復元しようとせず、現状のコードの内容に適したコメントを新規で書く。

---

## .hファイル
共通部分に準拠する。

- コメントは `///<summary>` 方式で書く。
- `<summary>` / 内容 / `</summary>` はそれぞれ改行し、内容部分は1行で書く。
- `//` 形式はできるだけ使用しない。

```cpp
///<summary>
///初期化。アトラスの読み込みも内部で行う
///</summary>
bool Initialize(...);
```

---

## .cppファイル
共通部分に準拠する。

- メソッドの外にはコメントを書かない。
- `///<summary>` 方式は使用しない。
- コメントは `//` 形式で1行で書く。

```cpp
void Foo()
{
    // ラスタライザ
    ...
}
```
